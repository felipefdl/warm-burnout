# Warm Burnout for Moshi

Even the phone terminal wants to scorch your retinas. Not on our watch.

## Install

Moshi imports themes from the clipboard or a pasted JSON document.

1. Install [Moshi](https://getmoshi.app) (iOS or Android)
2. Open the dark or light theme file from this directory
3. Copy the full JSON
4. In Moshi: **Settings → Theme → Import theme** → paste

GitHub Releases attach `warm-burnout-moshi.zip` with both files.

## Configure

After import, select:

- **Warm Burnout Dark**: for the 3am sessions
- **Warm Burnout Light**: for when someone forces you to open the blinds

Moshi derives the entire app chrome from the palette (sheets, buttons, home, inbox), not only the terminal viewport.

## Verify

Connect a session and run any ANSI color test. Background should stay warm stone, not pure black. Cursor is gold on dark, brass on light.

## Palette

Both themes derive from the canonical Warm Burnout palette in the root [`AGENTS.md`](../AGENTS.md). The 16 ANSI colors and editor background, foreground, cursor, and selection match the Ghostty theme exactly.
